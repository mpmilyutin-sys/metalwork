# Источники материалов

- Логотип и модели оснастки: https://metalw.ru/.
- Иллюстрации производственных сцен созданы с помощью ImageGen для этого макета.
- Иконки карточек выбраны по предоставленным пользователем образцам набора:
  https://www.vecteezy.com/vector-art/82303445-software-development-and-programming-icon-set-featuring-coding-symbols-and-web-infrastructure-design.
  SVG получены трассировкой контуров предпросмотра, а не скачиванием оригинальных
  векторов автора. Трассировка не изменяет условия использования исходного набора.
- Остальные используемые векторные значки и линии схемы сохранены в файлах сайта.
