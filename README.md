# Metalwork

Дизайн лендинга «Металворк». Статический сайт на HTML, CSS и JavaScript.

## Просмотр и редактирование

Сайт находится в папке `dist`. Основная страница: `dist/index.html`.
Стили и скрипты лежат рядом, изображения и SVG в `dist/assets`.
Для локального просмотра запустите из папки `dist`:

```sh
python -m http.server 4173
```

Откройте http://127.0.0.1:4173/.

## Публикация

GitHub Actions публикует содержимое `dist` в GitHub Pages при изменении ветки `main`.
В настройках репозитория Pages должен быть выбран источник GitHub Actions.
Восстановить предыдущую версию можно отменой коммита в `main`.

## Состояние макета

Форма демонстрационная: данные не отправляются. Ссылки MAX и Telegram пока ведут
к блоку обращения; адреса компании ещё не добавлены.
Изображения цеха созданы для иллюстрации, фотографии и модели из портфолио взяты
с исходного сайта metalw.ru. Источники графики указаны в `CREDITS.md`.
